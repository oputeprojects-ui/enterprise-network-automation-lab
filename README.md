# Enterprise Network Automation Lab

A production-style Cisco enterprise LAN and WAN automation project using:

- Cisco Modeling Labs
- Terraform
- Ansible
- pyATS and Genie
- Git and GitHub
- GitHub Actions or Jenkins
- Windows Server Active Directory, DNS and DHCP
- Linux infrastructure services
- Network monitoring and logging

## Project Objectives

This project will build a repeatable enterprise network containing:

- Headquarters and branch networks
- Cisco routers and switches
- VLAN segmentation
- Inter-VLAN routing
- Redundant core switching
- OSPF and BGP routing
- WAN connectivity
- Active Directory
- DNS services
- DHCP services
- Network monitoring
- Centralised logging
- Configuration backup
- Automated testing
- CI/CD deployment controls

## Automation Responsibilities

| Tool | Responsibility |
|------|----------------|
| Terraform | Create the CML topology, nodes, interfaces and links |
| Ansible | Configure routers, switches and network services |
| pyATS | Validate routing, switching, services and connectivity |
| Git | Version control and change history |
| GitHub Actions/Jenkins | Automated validation and deployment pipeline |

## Planned Implementation Phases

1. Workstation and repository preparation
2. Cisco Modeling Labs deployment
3. Basic LAN topology
4. VLAN and inter-VLAN routing
5. DNS and DHCP deployment
6. Headquarters and branch WAN
7. Network redundancy
8. Security hardening
9. Monitoring and logging
10. Automated testing
11. CI/CD pipeline
12. Client-ready documentation
